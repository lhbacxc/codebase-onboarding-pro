# 与 ECC 原版的升级差异

该提交是本地定制时使用的原版来源，也是本次查询时上游 main 的提交。以下比较固定到该提交，便于后续复查，不随上游 main 变化。

上游另外提供中文翻译，本说明比较的是上述英文原版；中文化与下列工作流程升级分别记录。

## 1. 将 CLAUDE.md 维护改为通用 AGENTS.md

原版的描述、触发示例和输出 2 面向 Claude Code，并生成或更新 `CLAUDE.md`。

Pro 版将目标改为项目 `AGENTS.md`，采用通用代理术语，并明确：

- 新建文件使用 `AGENTS.md`。
- 已有 `Agents.md` 等大小写变体时先读取并沿用，避免重复文件。
- 先读后合并，保留用户规则、人工内容和仍有效的项目约定。
- 已有针对特定工具的有效说明可以保留，并标明适用范围。

原版已经要求保护已有指令；Pro 版保留并细化了这一要求。

## 2. 新增开发后的增量维护模式

原版采用四阶段入门流程。生成或更新项目指令时执行阶段 1–3，再生成或合并文件。

Pro 版将完整流程保留为模式 A，并新增模式 B：确认范围与入口、复用当前任务证据、判断长期事实是否变化、合并必要文档、核对交付。

为已有项目生成或更新 `AGENTS.md` 时优先使用模式 B；证据不足才补充模式 A 的必要检查，不例行重跑完整分析。

## 3. 扩展自主触发范围

原版的使用场景集中于首次打开项目、加入仓库，以及用户提出入门或生成指令请求。

Pro 版在 skill description 和正文中增加开发结束、重构、配置调整和排障后的检查：只要产生应长期保留的项目事实，就按任务含义选择增量维护，无需用户说出技能名称或“更新 AGENTS.md”。

这是一套供代理执行的规则。skill 是否被选用仍由代理的发现与调度机制决定；它没有后台进程、文件监听器或定时任务。希望项目持续明确执行该规则时，可参考 [README 中的项目文档维护片段](../README.md#使用示例)。

## 4. 明确哪些事实可以写入长期文档

Pro 版将长期维护范围限定为：

- 架构、目录职责、环境和关键依赖。
- 启动、构建、测试命令及开发约定。
- 经实际验证、可以复用的排障约束。

局部算法细节、一次性日志、猜测、未经验证的命令和敏感信息不写入长期文档。已有验证失败或未完成时，说明适用范围，不宣称验证通过。

## 5. 增加无变化时的结束规则

普通局部实现或格式修改没有改变长期事实时，保持文档不变，不生成完整入门指南，也无需单独报告例行检查。

例如修正按钮间距通常只交付局部修改；调整测试入口并确认新的环境约束则需要同步相关项目文档。

## 6. 尊重项目已有文档分层

原版主要围绕单个 `CLAUDE.md` 维护项目说明。

Pro 版要求详细事实进入项目已有文档，`AGENTS.md` 只保留执行规则、关键约束与相对路径入口。项目事实不写入全局代理规则或 skill 本身。

原版建议生成的指令不超过 100 行；Pro 版将其作为新建文件的建议，不为满足行数删除已有有效规则。

## 7. 中文化及文件规范

标题、正文、模板和示例统一为中文，专有名词、YAML 字段、命令与文件路径保留原样。skill 要求生成资料遵循用户语言、使用 UTF-8，项目文件引用使用相对路径。

没有新增固定的 Python、Conda 或其他项目环境假设，也不会把维护者本机路径复制到其他人的项目中。

## 8. 补充代码索引使用原则

原版建议使用 Glob/Grep 做定向查找，避免逐个读取整个仓库。

Pro 版保留按需定位原则：当项目配置了 CodeGraph 等索引时，遵循项目要求优先使用索引理解代码，并按索引新鲜度提示补读必要文件；没有索引时使用定向文件列表和搜索。

本 skill 没有绑定特定 CodeGraph 版本，不负责自动安装索引工具或重建索引。

## 9. 独立命名与作者信息

技能名由 `codebase-onboarding` 改为 `codebase-onboarding-pro`，新增 `metadata.author: Lhbacxc`，保留 `metadata.origin: ECC`。发布保留上游 MIT 许可证及 Affaan Mustafa 的版权声明，并注明 Lhbacxc 的修改版权。

名称区分便于单独安装和维护；是否覆盖本地文件由安装路径与安装器行为决定。未来上游升级需重新核对和合并。

## 保留的原版能力

- 项目概况检查的六类信号及两层目录快照。
- 技术栈、架构、入口、目录职责及请求数据流分析。
- 命名、错误处理、异步、测试和 Git 约定识别。
- Git 历史不可用或过浅时明确说明无法识别约定。
- 入门指南与项目指令模板，以及实际命令与示例路径。
- 以代码事实为准、明确未知信息、避免复制 README 和罗列全部依赖。
